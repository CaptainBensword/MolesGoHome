# THREADLINE

A browser-based 3D city-swinging superhero game.

## Play

Open the GitHub Pages site after deployment. No build step is required. The game loads Three.js from jsDelivr.

## Controls

- **Mouse** — look around
- **WASD / Arrow keys** — run
- **Space** — jump
- **Hold left mouse button** — zip toward the closest rooftop anchor in front of you
- **Release left mouse button** — launch away with your current momentum
- **R** — respawn
- **Esc** — pause

## Objective

Find and collect the five glowing rooftop relays scattered across the city.

## Notes

This is an original superhero traversal game with an original character and setting. It is a single-page project designed for GitHub Pages.
